# Business workflow matrix

Derived from page API calls, controller actions, stores and response paths. These are 24 traceable scenario families, not proof that workflows pass. Each write follows the complete client → request → validation → logic → SQL → serialized response → UI chain. Admin and family/teacher reads must agree on shared data.

External Email/WhatsApp delivery is queued/blocked in source; no registered delivery background worker was found. Payment records are offline/manual ledger operations; no card gateway integration was found. Confirm business expectations before adding payment gateway tests.
