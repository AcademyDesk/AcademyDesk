## G03 — effective permission and action matrix

These controllers lack local Authorize attributes but the global AcademyAccessFilter gates every academyId action. Anonymous→401; ordinary users must match tenant, active academy and enabled module. Program active-Identity check still applies. Owner/AcademyAdmin then pass; IsPlatformOwner flag bypasses tenant/module/permission checks and generic audit. A PlatformOwner role string alone is not that flag.

| FinanceGovernance.Save | Same gate; full settings validation/upsert; 200 summary. No stronger branding/tax permission. Blank optional strings safe via Clean; storage errors still need friendly validation |
