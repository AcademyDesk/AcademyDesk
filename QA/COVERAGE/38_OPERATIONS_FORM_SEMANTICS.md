## G02 — FINANCE-FORM-001 Expense field → request → storage

The five form controls are React state, not FormData names. `createExpense` builds JSON itself. The category selector's hidden `expenseCategory` name is **not** the outgoing key; the request sends `category`. The page has no expense Update editor, so the Update API and BUG-DATA-0047 remain separate.

| Visible input / source | Outgoing `POST /api/academies/{academyId}/expenses` and DTO | Server and persistence boundary; existing FINANCE-FORM-001 variants |
| --- | --- | --- |
| Description, required text, `description` state | `description` string → nonnullable `CreateExpenseRequest.Description` | Browser truthiness gate rejects empty but not spaces; server rejects null/blank/whitespace, trims accepted text. `Expense.Description` required, max 300. Probe blank/space, Unicode and trimmed lengths 299/300/301, malformed/null JSON and no-write on rejection |
| Amount, required number with min 0.01 and step 0.01, `amount` string state | `amount: Number(amount)` → decimal | Browser truthiness permits `"0"`; native min blocks ordinary submit, direct API requires >0. EF decimal(18,2), no max/scale 400 guard. Probe 0, negative, 0.001, 0.01, 18-digit/precision and nonfinite/invalid client states, comparing serialized value and actual SQL outcome |
| Category select, defaults General, `expenseCategory` mirror | `category` from state → nullable string | Server blank/whitespace defaults General; otherwise trims. Required storage max 80; no server category allowlist, although UI offers General/TeacherPayout/Rent/Utilities/Marketing/Supplies/Equipment. Probe direct unknown and lengths 79/80/81; distinguish UI filter labels from persisted category |
| Branch select, optional `branchId` mirror | `branchId: branchId || null` → nullable Guid | Create verifies the ID belongs to route academy, else 400; null is accepted. No Expense branch FK is declared in this mapping; do not infer deleted-branch behavior. Probe empty/null, valid local, missing/foreign/inactive and stale lookup, with fresh row and denied no-write |
| Expense date, optional `expenseDate` mirror | `expenseDate: expenseDate || null` → nullable DateOnly | Null defaults to server UTC today; supplied date retained with no local range guard. Probe empty, malformed API date, leap year, timezone near midnight and date-year picker. Verify whether user intended local academy day versus UTC default |

The UI hardcodes `currency: "INR"`; API defaults a blank direct request to INR, otherwise uppercases and trims; EF requires max 3, with no ISO currency allowlist. `Status` is not an input: the entity defaults `Recorded` (max 30). `AcademyId` comes from the route after the global filter; the body cannot select another tenant. Test unknown currency through API, duplicated submit and cross-tenant branch, but do not count currency/status as native form declarations. Response is HTTP 201 with an `ExpenseSummary`; page checks only `response.ok` and does not inspect the body.

## G02 — FINANCE-FORM-006 Finance Policy field → replacement settings

FormData comes from a rendered form after settings GET. The `PUT /api/academies/{academyId}/finance-governance/settings` sends a **replacement** object, not a partial patch. Every field below maps to `FinanceSettingsRequest`; server Save upserts a unique AcademyId row. Missing row GET returns empty/GST/0/7/false, null branding, Classic/Standard. `save` does not reload after success; it uses the response summary and sets `Finance policy saved.`. These fields are separate from the six theme/branding controls in FINANCE-FORM-003 on the governance page, which can set a nondefault payslip theme.

| Form input | JSON transform and server rule | Storage/boundary test |
| --- | --- | --- |
| `taxRegistrationNumber`, optional text | `FormData.get` string/null; null→empty, otherwise trim | Required string max 50. Probe omitted, whitespace, trimmed 49/50/51 and Unicode |
| `taxLabel`, optional text | Null/blank/space→GST, otherwise trim | Required string max 30. Probe 29/30/31 and default; empty is not persisted as an empty label |
| `taxRatePercent`, number step 0.01, no required/min/max | `Number(FormData.get(...))` → decimal; blank becomes 0 | API range 0–100, EF decimal(6,3). Probe -0.001/0/100/100.001 and 3/4 fractional digits via API; distinguish HTML step from storage precision |
| `defaultPaymentTermsDays`, number, no required/min/max | `Number(FormData.get(...))` → int; blank becomes 0 | API range 0–365. Probe -1/0/365/366, decimal/invalid JSON binding and unintended blank-to-zero change |
| `taxInclusivePricing`, checkbox | `FormData.get(...) === "on"`; unchecked→false | Boolean replacement. Test checked/unchecked, stale form and simultaneous changes to another settings editor |
| `invoiceLogoUrl`, `invoiceSignatureUrl`, optional URL inputs | Raw string/null; server `Clean` trims blank/space→null | Nullable strings, no explicit max length, scheme/host allowlist or upload in model/controller. Browser URL validity is not direct API validation. Probe absent/blank/long/scheme/failed image |
| `invoiceAuthorityName`, `invoiceAuthorityTitle`, optional text | Raw string/null; server `Clean` trims blank/space→null | Nullable strings with no explicit max length. Probe null/empty/long/Unicode and rendered document behavior separately |
| `invoiceTemplateKey`, select | FormData string; null→Classic; exact Classic/Modern/Minimal/Formal else 400 | Required string with no explicit EF max length. Test each exact option, malformed/case variant, unchanged save and fresh read |
| **No `payslipTemplateKey` input is rendered** | Code still sends `FormData.get("payslipTemplateKey")` = null; null→Standard in Save | Existing Compact/Professional is silently replaced by Standard on an ordinary invoice/tax edit. Distinct BUG-DATA-0053, FINANCE-POLICY-PRESERVE-001; seed a nondefault theme through FINANCE-FORM-003 or API, save policy, fresh-read both themes and tax fields |

## G02 — OPERATIONS-FORM-001 Work Queue field → request → storage

The seven form controls assemble one `CreateWorkItem` JSON object. `type`, `priority`, `assignedUserId`, `dueDate` and `dueTime` live in React state; `title` and `description` come from FormData. `StandardSelectField` mirrors do not cause these state fields to be read from FormData. `entityType`/`entityId` are explicitly null; status is server default Open.

| Form input | Outgoing JSON / DTO | Server/persistence and boundary test |
| --- | --- | --- |
| Required `title` text | `form.get("title")` → nonnullable string | API rejects null/blank/space, then trims. Required max 240. Probe trimmed 239/240/241, Unicode, null/empty and no-write |
| Area `type`, default Operations | State → `Type` string | API rejects blank/space, then trims; required max 60, **no** server type allowlist despite six UI options. Probe each option, unknown, 59/60/61 and stale state |
| Priority, default Normal | State → nullable `Priority` | API allows exact Low/Normal/High/Critical, null→Normal. Empty string fails the allowlist before the later whitespace default; case variants fail. Required max 20. Probe UI/direct API null/empty/unsupported |
| Owner, optional `assignedUserId` | State `|| null` → nullable Guid | Saved without a user/academy/role check (existing BUG-DATA-0048). Probe local/foreign/missing/inactive ID plus null and fresh queue display; do not add another issue |
| Due date + due time, date optional and time defaults 09:00 | If date present: `new Date(\`${dueDate}T${dueTime}:00\`).toISOString()` → one nullable UTC `DueAtUtc`; otherwise null | No server date-range rule or explicit EF precision/length; invalid local value throws before request. Probe date absent (time ignored), 00:00, timezone/DST gap or overlap, year leap/end, empty/invalid time and ISO offset from direct API. Fresh GET renders browser local time |
| Context textarea `description`, optional | `form.get("description") || null` → nullable string | Empty becomes null; nonempty whitespace is trimmed by API and can persist as empty string. EF max 4000. Probe null/empty/space, trimmed 3999/4000/4001 and Unicode |

Create stores assignee/entity IDs without relation validation (BUG-DATA-0048). The queue filter is read-only and triggers GET with optional status; per-row status selector PATCHes Open/InProgress/Completed/Cancelled and sets CompletedAtUtc only for Completed. These are separate non-form controls registered in Batch 31 and action-permission traced in Batch 36. Test filter/query races, row identity, invalid status/no-write and status message independently of create.
