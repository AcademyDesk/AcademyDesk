## G03 — access and academy lifecycle

AcademiesController has Authorize. List has no academyId argument and therefore bypasses the global tenant filter; it resolves current Identity user's AcademyId, returns empty if absent, otherwise only that academy, including inactive status. It does not list all tenants for a platform owner. Anonymous must deny; deleted/missing Identity, active versus inactive account, unassigned and cross-tenant users need full-pipeline assertions. Account inactivity middleware and academy inactivity are distinct gates.

Create also has no route academyId: any authenticated unassigned user can provision an academy, with no Owner role prerequisite; an assigned user gets409. Registration UI calls this an owner account, so record this as the present self-service bootstrap policy, not automatically a privilege escalation. Confirm production registration/self-service intent using batch03 identity-endpoint review. Name required, legal optional, CountryCode defaults IN and uppercases; request TimeZone is ignored and Asia/Kolkata is hardcoded. New entity uses Trial/Core defaults,100 students,10 staff, no subscription expiry; this differs from platform onboarding with catalog configuration and30-day expiry. Specify parity/policy tests without claiming these paths already share defaults.

Create saves academy first, then ensures Owner role (checks that result), sets existing user's AcademyId and DisplayName to academy name, ignores UpdateAsync and AddToRoleAsync results, then returns201. Extend BUG-DATA-0011 for false-success assignment/role failures. A role-create failure or Identity exception can leave an orphan academy; retries can create another if assignment never persisted. Two concurrent create calls can both observe unassigned state. Failure-inject each stage and assert fresh academy, Identity, role and response state. Do not infer transactionality across contexts; recoverability and idempotency need explicit policy. DisplayName overwrite of an existing person is current behavior, not a new name field.

Update and SetActive have academyId: global filter requires active same-tenant academy and Core for ordinary callers, then Owner/AcademyAdmin because neither controller has a PermissionCatalog mapping. settings.manage grants alone do not allow access. Action adds its own user.AcademyId equality guard, so flag-only platform owner without matching academy is forbidden here despite filter bypass; use platform-owner endpoints for cross-tenant management. Test all named roles, custom grants, anonymous, foreign/missing IDs, suspended academy and missing Core. Do not remove owner/tenant guards to make a test pass.

SetActive permits an authorized same-tenant admin to deactivate their active academy. Subsequent self-reactivation is blocked by global inactive-academy gate; platform SetStatus remains the recovery path. No active-toggle control exists in /admin/control. Test this direct API sequence in disposable fixtures, explain recovery policy and ensure accidental suspension is not falsely presented as locally reversible. Existing sessions, ordinary writes and List visibility after suspension must match documented boundaries.

BranchesController lacks Authorize attribute but all actions carry academyId and the registered global AcademyAccessFilter checks Identity. Do not infer public access from the attribute alone. Same-tenant active MultiBranch plus Owner/AcademyAdmin is required; platform flag bypass is allowed. No branch-specific permission mapping. List/Create check academy existence, Update scopes branchId AND academyId; global filter may403 missing academy before an action404 for ordinary actors. Test exact HTTP pipeline, foreign branch404 with valid own academy, inactive branches and valid/null relationships. Owner/admin filter audit runs after domain save; reuse BUG-API-0002 partial audit failure and rejected-action logging cases.

## Persistence and downstream contracts

Academy Update returns normalized profile; no subscription/limit/status fields are editable through it. Profile save updates academy state/country/timeZone from response but name/legalName inputs use defaultValue; verify trimmed normalized values and later reload rather than assuming DOM reinitializes. Test two-edit/toggle races, duplicates, stable row identity, Cancel while save pending and editing another row before previous response. Branch counts include all rows and split IsActive.
