## Financial eligibility and balance invariants

Queue sums only Completed payments, then totalAmount-paid; no AdjustedAmount and no invoice status. Reminder UI repeats Completed-only and gross arithmetic. Reconciled payments/approved adjustments therefore inflate requested balance (existing BUG-DATA-0001/0002). Cancelled invoices with positive gross balance can create notices (new BUG-DATA-0019). Use independent decimal oracle with Completed/Reconciled/Voided combinations, approved/rejected adjustment, unpaid/partial/settled/overpayment and Cancelled/Paid/Issued/Overdue states; cancelled must create zero notices even if inconsistent money remains.

UI total and row money always INR regardless of invoice.currency (extension of FINANCE-CURRENCY-001), while message uses stored currency. Bulk chooses due<=today but UI All includes future positive balances; Queue all does not send every displayed future invoice. Overdue filter compares date parsed at midnight with current instant, while server uses UTC date; due-today and timezone boundaries need explicit labels/expectations. Filter selection does not affect bulk request. Displayed outstanding is not evidence of server eligibility. No date-input/year-picker changes apply to this page.
