## Design and scope

Use the existing Academy Admin shell; do not merge the v0 demo shell. A compact PENTA header leads to a bordered search panel, explicit student/batch choice, labeled query and one search action. Results are separate source-grounded cards with active status, as-of/timezone, optional batch code and source details. Mobile stacks the query/actions and result cards; existing theme tokens supply light/dark colors. No fictional alerts, balances, schedules or automation controls.

Authority comes from the current session's academy and the existing server pilot policy, never a user-selected tenant. Search is 2–80 characters, active-only and capped at 10. Students open the supported Student 360 query link; batches explicitly open the list. Typing, switching domain, cancellation and unmount invalidate older responses. Unexpected tenant/tool/source/link responses fail closed. No model call or domain write is introduced; existing read audit remains mandatory.
