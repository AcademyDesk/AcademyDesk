## Repair scope

- Existing submission GET and review PATCH now include student name/number, assignment title and batch identity. Every lookup independently requires the route academy, including invalid legacy references. Missing or foreign references return null context, never foreign labels. All original submission fields, list filtering/order, review payload and POST behavior are preserved. No new broad people lookup or endpoint, permission/module change, schema/migration or teacher access expansion.
- Each row shows learner, assignment, batch, status, UTC submission time and the stable student/assignment/submission IDs. IDs distinguish duplicate names/titles and missing labels; long text can wrap. Review actions have contextual accessible names; the feedback prompt identifies the exact record. Nullable response/feedback remain supported.
- Cancellation sends no request. A synchronous guard and disabled actions prevent duplicate concurrent page submissions. Only a structurally valid matching student/assignment/submission response with the expected feedback and Reviewed status replaces the clicked row. Successful save is announced; HTTP/network/malformed failures retain the row/action and advise checking the stored record before retrying (a lost response may follow a committed write). Failed/malformed loads do not falsely claim an empty queue. Load effects ignore stale unmounted responses.
- Native prompt retained; no new dialog/focus system or redesign of submission creation policy. BUG-DATA-0042 unchecked student/client lifecycle fields is deliberately deferred to the next bounded task.
