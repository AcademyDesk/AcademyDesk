## Bounded repair

Only apps/web/src/app/compliance/page.tsx changed in application code. Student choices come exclusively from the student table; Parent choices exclusively from guardians. Each form has its own controlled selection. Changing type clears only that form's person ID. Empty/unsupported/opposite-table/missing selections send no POST. Names in both existing ledgers resolve by the stored reference's type, including same-ID collisions across the two tables; unavailable subjects expose typed IDs, dual-reference legacy rows say Ambiguous rather than guessing a valid relationship. No legacy data rewrite or guardian-child relationship rule.

The form element is captured before awaiting HTTP, avoiding null currentTarget.reset(). Confirmed creation resets only that form's native fields, type/person and (for documents) expiry/visibility; the other form is not reset/remounted. Blank optional references, null expiry and AdminOnly default remain in the original payload contract. Failure retains both drafts. Explicit notice tones replace substring inference; success survives refresh. Review/withdraw share the same feedback path, with original PATCH routes/bodies retained and no draft reset.

A synchronous page-local lock plus disabled fields/actions prevents duplicate/cross-form writes while a write or refresh is pending. HTTP failures unlock without reset. Network uncertainty retains drafts, blocks more writes and advises fresh readback before retry. Successful write plus failed readback remains success with a refresh instruction, blocks writes until Refresh records succeeds. Refresh uses the selected route academy instead of reselecting the first academy. Initial non-OK/non-array loads do not claim an empty queue; complete array reads replace the four datasets together. This is not full runtime row-schema validation, API idempotency, concurrent-tab protection or an audit transaction.

Shared select/date controls, CSS/navigation/session, API/DTO/schema/access/storage and normal assemblies unchanged. Native required type/file fields remain; existing local-date expiry/time rendering and initial first-academy selection are not redesigned.
