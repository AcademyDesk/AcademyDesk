## Delivered

- Added `MeetingOperation` and `MeetingOutbox` mappings and migration `20261015122653_MeetingOperationOutbox`. Operation stores actor/academy/receipt references, provider/kind, bounded idempotency/hash/source/protected-envelope fields, state and concurrency version. Default is **Held**, not executable. No actual canonical payload encryption/admission path is added; protected-envelope population and integrity validation belong to the forthcoming authorized admission boundary.
- SQL unique indexes protect `(AcademyId,Kind,IdempotencyKey)` across actors and `(AcademyId,ReceiptId)` against duplicate receipt use. These are persistence constraints, NOT a consumed execution permit or an approval. Composite academy/operation foreign key prevents an outbox row referencing another academy's operation; restrictive delete and version/lease/status constraints apply.
- Internal `MeetingOperationStore` handles bounded leases, exact version/token fencing, durable dispatch markers and recovery. Every successful transition changes operation+outbox versions and saves a required initiator-bound audit in one SQL SaveChanges transaction. Concurrency loss returns false, never successful ownership. Store has **no production DI registration, route, admission method, worker, provider adapter or network calls**; only application test/harness friend assemblies exercise it.
- PendingDispatch → Leased → Dispatching transitions require exact current persistence fence. An expired Leased item can return to PendingDispatch because no dispatch marker was committed. An expired Dispatching item, or explicit uncertain result from its live lease, becomes **AwaitingReview**, never automatically retryable. Held cannot be claimed. Stale/foreign-scope/missing-outbox/wrong-token/version or live-lease recovery requests fail closed. No Created status or provider-success claim is supplied by this foundation.
- Migration downgrade refuses any operation/outbox evidence. Existing payroll nullable-PaidAtUtc and receipt snapshot changes retained. Existing controller/readiness/preview/review behaviour, RBAC, tenant rules, strict requests and all unavailable capabilities unchanged.
