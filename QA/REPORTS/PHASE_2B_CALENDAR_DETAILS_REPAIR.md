2026-10-01, Sol High bounded repair of accepted [BUG-DATA-0036](../ISSUES/BUG-DATA-0036.md). Accepted audit evidence reused; no whole-source re-audit. Issue/Phase2B remain OPEN for browser/device/all-linked/critical release acceptance.

## Result and fallback contract

The [calendar page](../../apps/web/src/app/calendar/page.tsx) now reads `Session.teacherId` and uses that saved assignment, not the current batch teacher. Null/missing/unresolved assignments display **Unassigned**, matching the unchanged [Schedule page](../../apps/web/src/app/schedule/page.tsx). The existing [session API](../../apps/api/Controllers/ClassSessionsController.cs) already resolves a default batch teacher at creation and persists the resulting assignment; Calendar does not invent a new live inheritance rule for null legacy sessions.

For Online/Hybrid classes, the trimmed session `roomName` is the authoritative location. Only missing/null/empty/whitespace locations fall back to the batch meeting link. A supplied non-URL or unsafe/invalid URL remains visible as text and is not replaced by a different meeting destination. Links must be absolute HTTP(S) URLs with a valid hostname, no whitespace and no username/password. Protocol-relative, JavaScript/data, malformed and credential-bearing URLs are not clickable. Existing HTTP links remain supported; this is not a backend meeting-domain validation policy.

Online/Hybrid comparison is case-insensitive, consistent with existing API acceptance. InPerson classes never gain a meeting action merely because their location resembles a URL or their batch has one. Grid and agenda share the same projected link. Agenda now shows Delivery and Location; location text wraps rather than being ellipsized. Existing external target/noreferrer, event/make-up internal actions, subject/student projection, filters and agenda collapse/expand are preserved.

No Schedule, Teacher portal, API/security/schema/migration or shared CSS changed. Teacher classroom/batch-wide Open behavior, default assignment/clash policies, timezone handling, calendar loading and other accepted gaps are outside this slice.
