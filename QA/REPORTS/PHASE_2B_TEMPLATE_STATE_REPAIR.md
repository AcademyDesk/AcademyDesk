# Phase 2B — Disabled template availability

2026-10-01. Bounded local repair of [BUG-FUNC-0029](../ISSUES/BUG-FUNC-0029.md), using the accepted Astra finding rather than re-auditing the portal. Issue and Phase 2B remain **OPEN**. Sol High remains suitable.

## Policy and implementation

- Disabled overrides `IsActive` at notification creation and in the compose selector, including contradictory legacy Disabled/active rows. Case/whitespace variants are recognized after lookup, independently of SQL collation. An inactive template is unavailable regardless of local status.
- Active Draft and Approved templates retain their existing usability, including Draft starter templates. No new approval prerequisite or provider approval claim is introduced. The supported-state policy is deterministic: Draft/Approved + active usable; Disabled never usable; inactive never usable. Other malformed/unknown lifecycle values are not newly classified by this narrow repair.
- API reads current scoped/active template state before notification/audit writes and returns400 with the existing unavailable message for Disabled. A disable committed before submission is enforced even when the loaded form still has an older selection. This is not serialization of a simultaneous disable/queue race.
- The page uses one availability predicate for options, selection and submission. A stale/forged unavailable ID is rejected locally with an unavailable message, separate from channel mismatch. Server rejection retains the composed title/body/variables/template for correction. Existing channel detachment, announcement payload, consent/connection rules and success/reset/readback behavior are preserved.
- Template Create/Update/List and starter creation are intentionally unchanged. Contradictory settings can still be stored, but consumers enforce Disabled; disabled entries remain available in the editing list. No migration, permission-catalog, global-filter or provider change. Existing queued notifications are not cancelled by this repair; dispatch/retry lifecycle remains a separate gate.
